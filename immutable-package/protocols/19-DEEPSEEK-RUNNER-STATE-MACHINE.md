# 19 — DEEPSEEK RUNNER STATE MACHINE (v2.1)

Source of truth: executable-orchestrator/lawmax21/states.py — this document is GENERATED by
executable-orchestrator/tools/generate_protocol19.py and validate_package.py fails on any drift.

Every transition requires, in order: (1) legality from the state derived from the SIGNED event
log, (2) the declared artifact validating against its JSON Schema, (3) the state's semantic
predicate, (4) for owner gates, an owner-signed approval bound to gate, run and artifact hash.
File existence alone advances nothing.

## States

- **UNINITIALIZED** — no signed transition recorded yet | next: PACKAGE_VALIDATED | guards: log-legality only
- **PACKAGE_VALIDATED** — full SHA-256 manifest, zero unlisted/missing, schemas enforceable | next: EVIDENCE_VAULT_CERTIFIED | guards: schema-guarded
- **EVIDENCE_VAULT_CERTIFIED** — every declared source present and non-empty | next: CHARTER_FROZEN | guards: schema-guarded
- **CHARTER_FROZEN** — objective frozen before any architecture selection; Vision must be EVIDENCE_BACKED | next: HIDDEN_BANK_COMMITTED | guards: schema-guarded
- **HIDDEN_BANK_COMMITTED** — merkle commitment + grader freeze + canary roster | next: ATTESTED | guards: schema-guarded
- **ATTESTED** — mode, paid-call count, package tree hash, no key material in builder scope | next: REPOSITORY_RECONSTRUCTED | guards: schema-guarded
- **REPOSITORY_RECONSTRUCTED** — every item carries executable evidence; UNKNOWN is allowed and explicit | next: HISTORICAL_EVIDENCE_SYNTHESIZED | guards: schema-guarded
- **HISTORICAL_EVIDENCE_SYNTHESIZED** — prior studies mapped with sourced lessons | next: GLOBAL_LAWMAX_MODEL_CERTIFIED | guards: schema-guarded
- **GLOBAL_LAWMAX_MODEL_CERTIFIED** — proof-of-ingestion: zero uningested byte ranges, citations verified byte-exact | next: TARGET_ARCHITECTURE_SEARCH | guards: schema-guarded
- **TARGET_ARCHITECTURE_SEARCH** — independent explorer contexts; at least three distinct families | next: TARGET_ARCHITECTURE_v0_REVIEWED | guards: schema-guarded, semantic-guarded
- **TARGET_ARCHITECTURE_v0_REVIEWED** — OWNER GATE — signed approval bound to (gate, run, artifact hash) | next: TARGET_ARCHITECTURE_v0_FROZEN | guards: owner-gate:GATE-ARCH-V0
- **TARGET_ARCHITECTURE_v0_FROZEN** — v0 artifacts hash-pinned | next: EVALUATION_PARAMETERS_FROZEN | guards: log-legality only
- **EVALUATION_PARAMETERS_FROZEN** — pareto dimensions and thresholds pinned separately from the charter | next: SUBSTRATE_BUILDING | guards: log-legality only
- **SUBSTRATE_BUILDING** — shared capability substrate assembled in an isolated worktree | next: SUBSTRATE_CERTIFIED | guards: log-legality only
- **SUBSTRATE_CERTIFIED** — visible suite passes across all capability slices | next: ARCHITECTURE_DISCOVERY | guards: schema-guarded
- **ARCHITECTURE_DISCOVERY** — candidate register: at least two distinct mechanisms | next: CANDIDATE_BUILDING | guards: schema-guarded
- **CANDIDATE_BUILDING** — each candidate written into its own worktree and compiled | next: VISIBLE_CERTIFIED | guards: schema-guarded
- **VISIBLE_CERTIFIED** — candidates measured head-to-head; a non-discriminating suite fails the guard | next: FIDELITY_CERTIFIED | guards: schema-guarded, semantic-guarded
- **FIDELITY_CERTIFIED** — ablation must move the score; hard-coded answers scanned | next: PRIVATE_QUALIFICATION | guards: schema-guarded
- **PRIVATE_QUALIFICATION** — hidden shards, isolated candidate processes, canaries all denied | next: PROVISIONAL_FRONTIER_MEMBER | guards: schema-guarded, semantic-guarded
- **PROVISIONAL_FRONTIER_MEMBER** — complete measured vector admitted to the frontier | next: CEILING_ANALYSIS | guards: schema-guarded
- **CEILING_ANALYSIS** — must name what the architecture cannot do | next: SUCCESSOR_SEARCH | guards: schema-guarded, semantic-guarded
- **SUCCESSOR_SEARCH** — evolutionary challenger from the reserved budget line | next: RADICAL_CHALLENGER_SEARCH | guards: log-legality only
- **RADICAL_CHALLENGER_SEARCH** — discontinuous challenger from the reserved budget line | next: SIMPLIFICATION_CHALLENGE | guards: log-legality only
- **SIMPLIFICATION_CHALLENGE** — can a strictly simpler design match the frontier? | next: FRONTIER_REVIEW | guards: log-legality only
- **FRONTIER_REVIEW** — dominance gate; only non-dominated candidates reach private shards | next: PRIVATE_REPLICATION, SUCCESSOR_SEARCH | guards: schema-guarded, semantic-guarded
- **PRIVATE_REPLICATION** — finalists replicated on a second sealed level | next: ANTI_SATISFICING_AUDIT | guards: log-legality only
- **ANTI_SATISFICING_AUDIT** — all eight checks resolved with evidence; unresolved items block | next: HESA_CANDIDATE, CEILING_ANALYSIS | guards: schema-guarded
- **HESA_CANDIDATE** — highest evidence-supported architecture; margin must be strictly positive | next: FINAL_HOLDOUT_EVALUATION | guards: schema-guarded, semantic-guarded
- **FINAL_HOLDOUT_EVALUATION** — single-use holdout, enforced by an owner-side ledger | next: ARCHITECTURE_EVIDENCE_SYNTHESIS | guards: schema-guarded
- **ARCHITECTURE_EVIDENCE_SYNTHESIS** — useful / decorative / refuted, per mechanism | next: TARGET_ARCHITECTURE_v1_REVIEWED | guards: log-legality only
- **TARGET_ARCHITECTURE_v1_REVIEWED** — OWNER GATE — signed approval bound to (gate, run, artifact hash) | next: MIGRATION_PLAN_FROZEN | guards: owner-gate:GATE-ARCH-V1
- **MIGRATION_PLAN_FROZEN** — OWNER GATE — waves with per-wave rollback; big-bang forbidden | next: INDEPENDENT_AUDIT | guards: schema-guarded, owner-gate:GATE-MIGRATION

- **BEST_DISCOVERED_SO_FAR** — honest terminal state when the target was not reached | next: — | guards: schema-guarded, semantic-guarded
- **HALTED** — honest terminal state on a blocking failure | next: — | guards: schema-guarded, semantic-guarded

## Terminal honesty

COMMITTED is not the only acceptable ending. BEST_DISCOVERED_SO_FAR and HALTED are first-class:
a run that did not reach the target must say so rather than relabel a lesser result.
