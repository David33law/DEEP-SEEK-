# 44 — SUCCESSOR & RADICAL CHALLENGER PROTOCOL (v1.3)
For EVERY provisional frontier member, generate at minimum four proposals:
1. **Evolutionary successor** — same mechanism family, ceiling-informed improvements (45).
2. **Radically dissimilar challenger** — different load-bearing principle entirely.
3. **Hybrid synthesis** — best-evidenced elements of ≥2 prior candidates.
4. **Simplification challenger** — strictly simpler design targeting the same capabilities;
   its victories are ARCHITECTURAL FINDINGS (complexity was unnecessary), not embarrassments.
Each proposal carries the full 06 object (capability claims, load-bearing mechanism, required
substrate, expected observable behavior, failure hypothesis, ablation contract, development
tests, transfer prediction, legal-use prediction) PLUS: predicted superiority (which Pareto
dimensions and why) and failure conditions (what result would prove it inferior).
Challengers are engineered under 13 equality on the shared substrate; evaluation identical
to originals (visible slices → fidelity → hidden cohorts → ablation). Results feed 42 and 35.
