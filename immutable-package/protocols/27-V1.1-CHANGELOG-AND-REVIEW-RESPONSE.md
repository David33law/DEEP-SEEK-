## Διευκρινίσεις πραγματικότητας (όχι αποδοχή σφάλματος)
- «Δεν περιέχει εκτελέσιμο πείραμα»: η εντολή κατασκευής της v1.0 όριζε ρητά «μην
  δημιουργήσεις ακόμη runner, πρώτα έλεγχος και πάγωμα». Η v1.0 ήταν εξ ορισμού design pack.
  Η v1.1 συνοδεύεται πλέον από Executable Scaffold (χωριστό zip) με τοπικό dry-run:
  0 API calls, 0 hidden exposure, 0 repo modifications.
- «Repository-agnostic»: δηλωμένο ανοιχτά στη v1.0, όχι εύρημα ελέγχου. Το GROUNDED ANNEX
  απαιτεί πρόσβαση στο repository, η οποία δεν έχει δοθεί στον συντάκτη. Συμφωνείται ο
  κανόνας: ΚΑΜΙΑ architecture proposal πριν ολοκληρωθεί το annex (04 ενισχύθηκε ήδη ως
  προϋπόθεση του ARCHITECTURE_DISCOVERY). Μπλοκάρεται σε απόφαση ιδιοκτήτη (24 §4).
- «Οι αποφάσεις εκκίνησης παραμένουν ανοικτές»: ακριβώς — γι' αυτό υπάρχει το 24· είναι
  blockers ιδιοκτήτη, όχι ελλείψεις πακέτου.

## Σημείωση μεθόδου
Ο έλεγχος λειτούργησε όπως πρέπει: έπιασε 2 πραγματικά bugs ακεραιότητας και 1 σχεδιαστικό
σφάλμα gating στον συντάκτη του πακέτου. Κανένα σύστημα — ούτε το παρόν — δεν «εξασφαλίζει
το ανώτατο δυνατό»· εξασφαλίζει ότι οι ισχυρισμοί αποδεικνύονται και τα σφάλματα πιάνονται.
Αυτό μόλις συνέβη, και προς τις δύο κατευθύνσεις.


# ΠΡΟΣΑΡΤΗΜΑ v1.2 (28.7.2026, μετά τον 2ο έλεγχο)
Το εύρημα του 2ου ελέγχου γίνεται ΔΕΚΤΟ στο σύνολό του: το v1.1 απαντούσε «ποιος μηχανισμός
περνά», όχι «ποια είναι η τελική δομή του LAWMAX και πώς μεταβαίνουμε σε αυτήν». Η διάκριση
Experimental Substrate ≠ Production Target Architecture υιοθετήθηκε ως ADR-0000.
Προστέθηκαν: 28 (synthesis protocol, 3 υποχρεωτικές εναλλακτικές, χωρίς προεπιλογή),
29-33 (v0 artifacts), 34-35 (evidence-revised v1), 36-39 (waves 0-7, cutover/rollback,
gates G1-G9, retirement register), νέες καταστάσεις στο 19, τελικός σκοπός στο 18.
ΟΡΙΟ ΕΝΤΙΜΟΤΗΤΑΣ (αμετακίνητο): τα 29/30/31 παραδίδονται ως σχήματα/πρότυπα + a-priori
invariants. Το ΠΕΡΙΕΧΟΜΕΝΟ τους (as-is πλευρά, components, OQ-λίστα) μπορεί να γραφτεί
ΜΟΝΟ πάνω στο REPOSITORY REALITY MODEL — οτιδήποτε άλλο θα ήταν κατασκευασμένη προέλευση,
δηλαδή η terminal violation που το ίδιο το πακέτο απαγορεύει. Καμία DeepSeek κλήση δεν έγινε.

καταστάσεις στο 19, ενσωμάτωση σε 14/18/22/24). Μία δεσμευτική εναρμόνιση προστέθηκε για
