# 01 — ΜΗ-ΣΤΟΧΟΙ ΚΑΙ ΟΡΙΑ (v1.0)

1. ΟΧΙ chatbot/γενικός βοηθός· ΟΧΙ αυτόνομη κατάθεση/αποστολή δικογράφων· ΟΧΙ επικοινωνία με
   αντιδίκους/δικαστήρια. Κάθε παραδοτέο τελειώνει σε human gate.
2. ΟΧΙ αυτοματοποίηση H1: σιωπή/αποκάλυψη, επιλογή εναγομένων/βάσεων, ένταση ύφους,
   συμβιβασμός, κατάθεση — μόνο εισηγήσεις με επιλογές.
3. ΟΧΙ ενσωμάτωση Case A-Box στο γενικό κώδικα: ονόματα, ΑΦΜ, πινακίδες, ποσά υποθέσεων
   απαγορεύονται σε core/substrate/fixtures-generators (μόνο σε case stores + anonymized fixtures).
4. ΟΧΙ κατασκευασμένες παραπομπές/προέλευση: fabricated citation ή fabricated provenance =
   terminal violation (κόκκινη κατηγορία στο 09/22), όχι «bug».
5. ΟΧΙ κρυφή αλλαγή thresholds/acceptance· ΟΧΙ MAX_ATTEMPTS-τύπου όρια· ΟΧΙ debugging στο hidden.
6. ΟΧΙ ισχυρισμοί «συνείδησης»: το self-model είναι λειτουργική αυτοεπίγνωση (components,
   capabilities, contracts, σφάλματα, όρια) — μετρήσιμη, όχι φιλοσοφική δήλωση.
7. ΟΧΙ πλήρης ελληνική νομική οντολογία στον 1ο κύκλο: T-Box μόνο για κανόνες που απαιτούν
   τα case studies/transfer cases. ΟΧΙ πολυδικαιοδοσία στον 1ο κύκλο.
8. ΟΧΙ ολικές επανεγγραφές συστήματος ανά γύρο· ΟΧΙ απόρριψη υπάρχοντος repo χωρίς το
   REPOSITORY REALITY MODEL να το τεκμηριώνει.
9. ΟΧΙ training/fine-tuning βαρών στον παρόντα κύκλο: νέα γνώση = νέες δομές T-Box/A-Box +
   μηχανισμοί, όχι νέα βάρη.
10. ΟΧΙ δίκτυο μέσα στα execution containers· ΟΧΙ secrets σε logs/commits· ΟΧΙ Git remotes.
