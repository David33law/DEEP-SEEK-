# 00 — ΚΑΤΑΣΤΑΤΙΚΟΣ ΣΤΟΧΟΣ ΣΥΣΤΗΜΑΤΟΣ LAWMAX (v1.0, frozen at OBJECTIVE_FROZEN)

## 1. Ορισμός
Το LAWMAX είναι μόνιμος, εκτελέσιμος, αυτοελεγχόμενος μηχανισμός νομικής νοημοσύνης.
ΔΕΝ είναι chatbot, RAG wrapper ή LLM-με-εργαλεία. Εξωτερικά μοντέλα = προσωρινά εργαλεία
πίσω από ports· το σύστημα παραμένει λειτουργικό αν οποιοδήποτε API πάψει να υπάρχει.

## 2. Δύο επίπεδα συλλογισμού (αρχιτεκτονική σταθερά)
- **Deliberation Workspace**: παραγωγή υποθέσεων, αναλογιών, στρατηγικών, αντιφάσεων,
  εναλλακτικών διαδρομών. Περιεχόμενο ΜΗ δεσμευτικό εξ ορισμού (epistemic ≤ EXTRACTED).
- **Certified Legal Reasoning Ledger**: εξωτερικευμένη, επανεκτελέσιμη, επαληθεύσιμη αλυσίδα
  είσοδος→πηγή→span→epistemic status→κανόνας→προϋπόθεση→γεγονός→αντίθετη εκδοχή→ενδιάμεσο
  συμπέρασμα→στρατηγική συνέπεια→ανθρώπινη απόφαση→αποτέλεσμα. Δομημένα proof objects,
  reasoning traces, argument graphs, decision provenance, audit trail — ΟΧΙ αφηγηματικό CoT.
Κανόνας ροής: τίποτα δεν περνά από Workspace σε Ledger χωρίς verification ή/και human gate.

## 3. Στοχευόμενο επίπεδο ικανότητας
Πρώτος ορίζοντας: πλήρης ΑΝΤΙΔΡΑΣΤΙΚΟΣ νομικός συνεργάτης (κλίμακα CS-01: L3) στα 16
λειτουργικά πεδία του αιτήματος (ingestion→προθεσμίες). Δεύτερος ορίζοντας: ΠΡΟΛΗΠΤΙΚΟΣ
επόπτης (L4). Η αξιολόγηση ΔΕΝ επιτρέπεται να παρουσιάζει mechanical integrity ως νομική
νοημοσύνη (βλ. 03 επίπεδα M/S/L/P/I και 17).

## 4. Ελάχιστη ουσιαστική επιτυχία 1ου κύκλου (δεσμευτική διατύπωση)
Σε ΑΓΝΩΣΤΗ υπόθεση, χωρίς case-specific hint, το σύστημα: εντοπίζει δυνητικά επιζήμια
βεβαιωτική διατύπωση στο δικό μας κείμενο· εξηγεί με πηγές+trace ποιον ωφελεί και σε ποιο
συνδεδεμένο νομικό βήμα· προτείνει ασφαλή αναδιατύπωση που διατηρεί το επιχείρημά μας·
περνά deterministic diff/invariant verification· ζητά τελική έγκριση δικηγόρου.
(= capability admission.detect + omission-safe rewrite σε transfer, με trace-grading.)
